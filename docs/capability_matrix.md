# 剪映 AI 编辑能力清单

依赖：pyJianYingDraft `0.3.1`。界面记录仍来自更早的 `0.3.0` 与剪映专业版 `10.0.5.13816`，升库后没有重跑界面。

实现状态：MCP 包含草稿批处理工具、既有加密草稿只读适配器和视频观察工具；默认试运行且不覆盖同名草稿。本次只增加版本 profile，不要求正在使用的生产环境升级。正式环境替换前须 wy 批准。

## 版本 profile

| profile | 状态 | 含义 |
|---|---|---|
| `10.0.5.13816` | 已验证基线 | 下表「已完成验证」只对这一版成立。界面证据记录于 pyJianYingDraft 0.3.0。 |
| `11.6.0.14552` | 待黑盒回归 | 已登记为目标版本。代码仍写明文草稿，但没有任何 11.6 界面结论。调用方必须转述「待黑盒回归」，不能写成已实测。 |

11.6 的已知风险：

- 在线资源 ID（特效、滤镜、动画、字体、气泡、花字、贴纸、文字模板）可能下架或更换，也受账号、会员和缓存影响。
- 加密模板读取有合规风险，并且和剪映版本强绑定。本步不修改 `draft_crypto.py`、`native/jy_draft_crypto.cpp`，不引入解密依赖，也不把 11.6 的加密读取标成可用。
- 剪映打开并保存后草稿会被重新加密。生成后能打开，不等于之后还能再程序化修改。
- 11.x 的 schema 没有公开文档。人工回归清单见 [jianying_11_6_blackbox_checklist.md](jianying_11_6_blackbox_checklist.md)。

蒙版：pyJianYingDraft 0.3.1 修复了新版蒙版，并在剪映 5.9 与 10.8 验证。`10.0.5.13816` 上曾经不显示，所以基线继续禁用。`11.6.0.14552` 只把蒙版登记为候选，写入仍然拒绝，等黑盒回归后再决定是否放开。

测试草稿使用前缀 `TEST-laowang-`，只新建不覆盖。文档不写本机绝对路径。

本清单按“能力类型”验证，不逐个测试同类预设。预设数量很大，实际可用性还受剪映版本、账号权限、会员状态、资源是否缓存和网络状态影响。

状态定义：

- `已通过`：草稿结构和剪映实际打开/效果均已确认。
- `结构通过`：接口生成和草稿结构通过，等待剪映界面确认效果。
- `部分通过`：基础结构可用，但存在版本或资源限制。
- `仅界面`：pyJianYingDraft/MCP 没有对应接口，需要剪映界面自动化或独立本地能力。
- `待测试`：尚未完成代表性验证。

## 视频观察器边界

- 默认 `efficient` 最多50张关键帧；`balanced` 最多100张场景帧；`dense` 最多200张。
- 建议生产任务先限制为24–40张，再对候选区间局部复查。
- 报告按输入、文件修改时间和参数缓存；同一分析不会重复抽帧。
- 当前转写是语句级时间戳。逐字字幕、口型同步、节拍检测和波形相关仍未实现。
- 纯文本模型只能消费字幕和已保存的画面描述，不能直接完成画面观察。

## 读取草稿和批量制作

目标流程：

1. 读取指定参考草稿。
2. 提取轨道、素材、文本、样式和效果结构。
3. 复制为新的工作副本。
4. 根据变量表批量替换素材、文本、时间和配色。
5. 做结构校验、素材存在性校验和权限检查。
6. 写入剪映草稿目录，要求剪映重启或刷新后打开。

当前边界：

- 明文草稿可直接读取、复制和替换，已通过。
- 剪映 10.0.5 打开并保存后的 `draft_content.json` 会加密。
- MCP 已接入经源码审计的 `jy-draftc` 兼容读取器，通过本机 `videoeditor.dll` 读取；不分发剪映 DLL。
- 原草稿从不原地解密或回写；解密发生在一次性副本中，完成后删除明文。
- 读取器仍受剪映版本的导出符号兼容性影响；状态检查失败时会明确报告，不能声称读取成功。
- 同名素材可能产生歧义；生产生成器应复用同一个 `VideoMaterial`，读取外部模板时使用轨道/片段选择器兜底。
- 文本轨导入前需要清理孤立引用，避免 pyJianYingDraft 0.3.0 的断言失败。

## Skill 交互模式

Skill 在规划前应让用户选择或自动判断以下模式：

1. `自动补全创作`：模型可补足镜头、节奏、转场、配乐、字幕样式和缺失细节。
2. `严格按照要求`：不得添加未明确要求的创作决策；歧义处先询问。
3. `参考草稿`：读取或复制指定草稿，明确哪些内容保留、替换或允许重新编排。

通用引导信息：成片目的、平台和画幅、目标时长、素材位置、字幕语言、配乐方向、参考风格、不可修改项、是否允许云端功能、是否允许会员素材、输出是草稿还是最终视频。

## 安全与执行规则

- 模型先输出简短剪辑计划，再提交一份批处理清单给 MCP。
- MCP 负责确定性执行，不让模型逐片段直接编辑 JSON。
- 执行时显示阶段事件，例如“分析素材”“规划时间线”“生成字幕”“写入草稿”“等待剪映刷新”。
- 检测到草稿目录 `.locked` 时拒绝替换，要求返回首页或退出剪映。
- 每次替换只操作明确命名的测试/输出草稿，并保留可恢复备份。
- 剪映已经加载的草稿不会自动读取外部变化；替换后必须返回首页并重启或刷新剪映。
