# 能力与兼容边界

版本 profile：

- `10.0.5.13816`：已验证基线。下面的「已验证」只属于这一版，界面记录时草稿库是 pyJianYingDraft 0.3.0。
- `11.6.0.14552`：待黑盒回归。同一份代码可以写明文草稿，但没有 11.6 界面结论，不能说已实测。
- 当前依赖是 pyJianYingDraft `0.3.1`。正式环境替换前须 wy 批准；这不是生产强制升级。

## 已验证

- 新建草稿、画布、帧率、多视频/音频/文本/贴纸/滤镜/特效轨
- 本地视频、音频、图片；截取、整体变速、画中画、混合模式
- 音量、淡入淡出、场景音、音色、声音成曲
- SRT 导入、文本字体/颜色/背景/阴影、描边 20、气泡、花字
- 转场、视频/文本动画、滤镜、画面特效、色度抠图
- 视频/文本/贴纸位置和缩放关键帧
- 明文参考草稿分析、复制、按片段换料/换字和批量制作
- 配置本地读取器后，加密参考草稿分析、复制和批量制作（只读源文件；只属于 10.0.5 基线，11.6 不算已验证）
- 本地视频元数据、代表帧、局部区间复查和分析缓存
- SRT/VTT 旁挂字幕解析、规范 SRT 输出

在线字体、贴纸、动画和效果可能受版本、账号、会员、网络与本地缓存影响。

## 禁用或降级

- 圆形等蒙版：10.0.5 未显示，继续禁用。0.3.1 在剪映 5.9 与 10.8 修复了新版蒙版；11.6 只是候选，待黑盒回归前拒绝写入。
- 模糊背景填充：结构可写，但 10.0.5 实测未显示；11.6 待黑盒回归，仍然拒绝写入。
- 音量关键帧：结构存在，但 10.0.5 界面未观察到；11.6 待黑盒回归，仍然拒绝写入。
- 已加密草稿：依赖 Windows、本机剪映 `videoeditor.dll` 和既有 `jy-draftc` 读取器。不为 11.6 改读取器，也不把加密读取说成已适配。版本导出符号变化时会明确失败。
- 视频语义：只观察抽取的代表帧，不是逐帧读取；快动作需要局部加密采样。
- 自动转写：可选 Groq/OpenAI Whisper 语句级时间戳，不是逐字强制对齐。

## 尚未实现

- 剪映内置音乐/音效库自动搜索与下载
- 剪映内置 TTS、自动字幕、文稿识别（独立字幕/Whisper 方案不操作剪映内置功能）
- 剪映节拍检测、自动卡点
- 剪映 7+ 的可靠自动导出
- 逐帧动作理解、精确口型同步和逐字字幕

上述功能需要剪映界面自动化、云服务或独立 ASR/视觉/音频模型。不要把代表帧观察描述成完整观看视频，也不要把草稿 JSON 生成能力描述成媒体理解能力。

## 版本规则

每次任务都调用 `get_jianying_capabilities` 并转述 `compatibility.message`。

- `profile_status=verified`：当前是 `10.0.5.13816` 基线。仍要说明在线资源可能受账号和缓存影响。
- `profile_status=pending_blackbox`：当前是 `11.6.0.14552`。必须说「待黑盒回归」。在线资源 ID 可能失效。加密模板读取有合规风险，本步没有适配。
- `unlisted` 或 `undetected`：预设 ID、草稿字段、在线资源和视觉呈现都可能变化，先生成小样并人工抽检。

测试草稿名称使用前缀 `TEST-laowang-`，只新建不覆盖。正式环境替换前须 wy 批准。
